# v29 prospective design and endpoints

Use no policy tuning on v29 evaluation. 24 independent blocks, each containing one independent environment cohort from each of the eight v28 target population laws. Matching v28's shift panel facilitates comparison; these are new worlds/contexts/numerical seeds but not new physics or new parameter strengths. Within-block environment order/tie breaking independent of hidden laws. For each environment, calibration x from 1024 iid worlds; independently randomized distinct probe recipients; evaluation x from 128 additional worlds, 32 paired potential observation noise repeats. Average over fixed shift panel, not over distribution of unseen shift laws. Sibling environments share only the preallocated resource budget; the method scores each independent environment separately. An environment loses future eligibility after stopping.

All four deployable policies buy exactly 32 calibration contacts per block. Fixed4 = 8x4. Adaptive = 8x2, then 4x2 more, then 2x4 more (final 4x2, 2x4, 2x8). Ranked prospective expected query/probe reversal weighted by decision margin after next 2 or 4 hypothetical observations; use only currently exposed x/y and independent simulator/reference bank. Additional equal-budget controls are random placement of same 2/4/8 multiset and uncertainty-only stopping. Numerical predictor/selector K256 (shared budget/seeds) and common known-population decoder for all methods, no individual latent parameters. Known-prior K256 spending zero calibration probes is privileged context, not budget-matched. Fix design and acquisition ledger before reading any test outcomes. Record stage rankings and expose only paid prefixes to adaptive policy. Offline 2/4/8 counterfactual costs and oracle diagnostics are evaluation-only.

Two co-primary paired common-decoder contrasts (adaptive minus fixed4). A: exact calibration budget, unconstrained downstream query/probe choice; report actual extra deployment probe counts, actual total difference. B: exact calibration AND total contacts: every environment ranks *all 128 contemporaneously available test factual vectors* with its deployment model, selects exactly 13 probes per environment by the positive risk(query)−risk(probe) score; query view for the rest; equal information and arrival contract for both strategies. 32 calibration + 104 test probes = 136 all contacts per block per deployable policy (same 8x128 additional observations). Batch quota is a secondary operating constraint relative to v28's unconstrained setting: do not silently transfer B's speed/risks to streaming. Simultaneous max standardized 95% bounds over two co-primary contrasts; supported improvement if upper bound<0, practical improvement of at least 0.003 if upper bound<−0.003. Do not claim generic superiority from only one setting. 10000 paired hierarchical bootstrap block resamples and paired worlds within selected cohorts. Under B, entire batch determines choices; primary CI for B resamples whole independent blocks (not individual evaluations) to respect within-batch dependence. Also report matched block-only intervals for both (computed together as confirmatory family) and conditional world-bootstrap for A as sensitivity. Secondary native risk, resource controls, gain/loss per stopped group and comparators descriptive. No counting 32 repeats as independent labels. Equal calibration power does not imply favorably-priced physical acquisition.

Compute: synchronized batch-one host to selected prediction p90 for A and separately warmed end-to-end deployment batch latency for B, actual hardware; cohort fit/rank/engine setup charged separately incl extra stage scoring and offline planning cache, compare amortized costs over 128 decisions/cohort; distinguish simulator/expected losses from actual robot duration. Report primary timing plus complete dynamic calibration cost if caching and incremental inference differ in benchmark. Physical probe counts and unit-price sensitivity, not fictitious wall-clock sensor costs. Baseline: exact random expectation from all budget potential outcomes; held-out audit of score vs actual future action switch and value (advantage) at both stages, only computed after choices frozen. Native and common-known decoders identified. All results guarded on same empty GPU, analyses on compute CPU.
