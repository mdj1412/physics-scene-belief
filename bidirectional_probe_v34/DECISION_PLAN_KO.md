# V34 사전 계획: 방향을 판독할 수 있는 것과 그 방향으로 결정을 개선하는 것

V34 정책 결과를 열기 전에 고정한다. 두 물체×두 표면은 v33에서 이미 알려진 합성 계열이다. v34는 해당 계열의 새 물체·새 seed를 쓴다. 방향을 바꾸는 calibration 물체는 같은 환경의 다른 물체들이며 같은 물체를 왕복해 측정하지 않는다. 양쪽 schedule 모두 첫 방향을 같은 block에서 공유하고 조합 내 start sign의 수를 맞춘다. 같은 물체, 표면 방향, paid count, noise에서 schedule만 바꾼 paired 효과를 추정한다.

1. 세 primary 정책은 fixed 4, friction coupling posterior SD를 쓰는 uncertainty-only, v32에서 동결한 broad 1×1 ridge scorer다. 양쪽 schedule에서 동등한 32 calibration 및 104 deployment probes를 쓴다. 주지표는 실제 stick label과 공통 source decoder 확률 사이의 held-out Brier다. 네 object–surface 가족의 여덟 block씩을 동일 가중하며 동일 orientation·schedule·정책에 같은 indices를 적용한다. 첫 방향을 균형화한 효과를 검증하기 위해 각 가족의 시작 방향별 4개 block을 별도로 복원추출한다. 세 정책의 alternating−same, 각 schedule 내 frozen−fixed, frozen−uncertainty, uncertainty−fixed의 9개 차이에 한 family의 simultaneous 95% interval을 쓴다. 0.003 absolute Brier를 실용적 기준으로 유지한다. Plus/minus orientation은 같은 물체이므로 독립 표본으로 중복 처리하지 않는다.
2. 새 gain heads: target의 object와 surface 양쪽이 겹치지 않는 대각선 family 한 곳만으로 stage별 ridge를 fit한다. 평가는 뺀 family의 새 worlds에서 한다. 따라서 한 fold 안에서는 training과 test가 물체 계열·표면 계열 모두 disjoint이나 4개 folds의 학습·평가 roles는 교차한다. 두 schedule을 동일 weight로 포함하고, input의 factual/paid 15 features, start sign, schedule flag, 사전에 정한 여덟 interaction 입력에 곱할 방향 cue를 공통으로 둔다. Cue는 무정보 0, 독립 CPU calibration corpus에서 학습한 estimated sign probability의 2p−1, oracle true sign, 같은 block의 paired orientations 사이에서 무작위 뒤집은 placebo(전역 orientation 빈도 및 같은 환경의 공통성을 보존)다. 같은 stage에서 모든 환경에 일괄 더한 sign intercept는 순위를 바꿀 수 없으므로 sign×prefix interaction을 포함한다. Ridge penalty λ=0.3, train-only normalization, ceiling 없이 두 stage를 재계산한다. Truth는 oracle 진단에서만 쓰고 deployed head는 paid observation만 받는다. 동일 target에서 candidate를 고르지 않는다. Qualifying feature: raw reader는 해당 held-out family의 실측 row나 direction label로 훈련한 적이 없어야 한다.
3. Stage의 supervised gain = archived R2−R4 또는 R4−R8이며 실제로 구매할 경우 생기는 Brier 변화다. 동일한 target의 같은 8개 환경에서 ranking→4곳→2곳을 수행한 뒤 최종 count의 실제 R을 읽는다. 사전 비교: 각 schedule에서 estimated−neutral, oracle−neutral, estimated−placebo, estimated−fixed4, estimated−uncertainty, 두 schedule의 estimated 간 차이(합계 11개); paired max-standardized bootstrap으로 한 simultaneous family를 만든다. Fold model의 변동을 무시하지 않기 위해 target·training cluster를 함께 재표집하고 gain heads를 다시 fit하는 sensitivity도 별도로 보고한다. 성능이 같다고 혼동하지 않도록 0.003 차이를 구간이 배제하는지 확인한다. p90은 실제 CPU scorer + CUDA posterior/acquisition/decoder의 synchronized wall time이며 로봇 이동·reset 대기시간 및 초기화는 제외한다. 새 heads는 양쪽 schedule에서 하나의 공통 모델을 쓰고 새 GPU source training을 반복하지 않는다.
4. Sign이 유용할 수 있는 다른 위치: fixed4의 최종 sensor choices와 예산을 그대로 두고, common decoder가 낸 선택된 observation의 확률에 대해 logistic recalibration을 한다. 입력은 기존 logit, action indicator, sign 및 sign×기존 logit/action interaction. 방향 없는 head와 estimated/true sign head를 같은 방식·정규화·고정 L2 penalty로 fit, 대각선 family에서 fit하고 target family에서 평가한다. 새 label을 보지 않은 out-of-family paired 진단이다. 이는 perception이 sign을 읽고도 allocation을 개선하지 못하는 경우, 적어도 terminal prediction에서 sign의 가치가 있는지를 구분하기 위한 보조 분석이다. 새로운 deployment observation이나 추가 calibration은 보지 않는다. Orientation-aware decoder 진단에 주 방법의 latency를 그대로 붙이지 않는다.
5. 독립 분해의 한계: classifier 성능은 관측 정보량의 하한이며 낮은 성능은 정보 부재를 증명하지 못한다. Gain head가 개선되지 않으면 해당 feature·가설 공간·학습량에서의 결과다. 알려준 sign으로도 허용한 정책이 좋아지지 않으면 기존 scorer가 유용한 정보를 버렸다는 결론을 보류한다. Family와 eight couplings는 고정됐으며 real physical policy accuracy로 외삽하지 않는다.

배포할 target family의 direction readout을 정한 뒤 gain training rows에도 같은 readout을 적용한다. 따라서 test 대상 family에 맞춘 sign encoder가 간접적으로 gain training에 섞이지 않는다. Placebo는 target truth를 input으로 사용하지 않고 두 orientation의 predicted cue를 cluster별 하나의 동전으로 swap한다(같은 permutation을 각 method, schedule, stage에 유지). 실제 real-time method가 아니라 배정된 cue와 환경의 연관만 끊는 음성 대조다. 방향이 같은 여덟 환경 안에서는 probability의 공통 성분만으로 순위가 달라지지 않도록 명시적 interaction으로 검증한다.

Terminal calibration 세부: original probability를 [0.001,0.999]로 clip해 logit을 만든다. Fixed4에서 고른 action과 공통 원 확률을 그대로 써 방향 cue(0, estimated, true)별로 6계수 logistic model(intercept, logit, probe, cue, cue×logit, cue×probe)을 사용한다. Train-only weighted normalization, intercept를 뺀 L2=0.001, 연산 절감을 위해 train logit만 0.02 단위로 묶고 test에서는 연속값을 그대로 쓴다. 모든 32개의 sensor noise에 같은 가중치를 주되 독립 표본으로 세지 않는다. Source는 반대 물체·표면 family 한 곳이며 두 schedule를 같은 비중으로 같이 학습한다. 분석 전 정한 여섯 대비(각 schedule에서 estimated−neutral, oracle−neutral, oracle−estimated)에는 한 family의 simultaneous interval을 사용한다. 이 진단은 baseline decoder의 관측 종류·latent prior가 주어진 조건에서의 효과다.

독립 전이: V34 방향 판독 결과만 확인하고 새 full-policy 결과를 보기 전에, V33의 별도 물체들에도 frozen V34 gain heads와 terminal recalibrators를 그대로 적용하기로 했다. 해당 archive를 이용한 규칙이나 λ의 재선택은 없다. V33 연구자는 이 평가 결과를 이전 연구에서 본 적이 있으므로 연구 전체에 대해 완전히 blind한 자료는 아니다. V33의 모든 첫 probe는 −1.10이므로 one-direction/negative-start에 대해서만 재현 근거가 된다. V34와 다른 32개 독립 block에서 same-vs-alternating 자체를 재검증하는 자료로는 사용하지 않는다. Native V33 fixed4 counts, probabilities 및 factual configuration을 재사용하되 missing paid rows는 서버 CPU에서 당시 seeds로 재생한다. Estimated−neutral, oracle−neutral의 stopping 및 terminal 대조 네 가지에 joint simultaneous interval을 구한다.
