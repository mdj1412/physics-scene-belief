# V34 방향 정보 검증 계획

시뮬레이션에서 정한 surface orientation을 binary label로 쓴다. Plus와 minus에 같은 물체, calibration indices, sensor noise, probe 순서를 배정하며 같은 방향만 사용하거나 처음 방향과 반대 방향을 번갈아 쓴다. 각 family의 각 block에서 여덟 coupling 환경을 모두 생성한다. 같은 시간에 두 schedule의 접촉 수를 2, 4, 8회로 맞춘다. 첫 접촉 방향은 각 환경 slot과 block index의 홀짝에 따라 배정한다. 각 family에서 시작 방향과 surface orientation이 균형을 이룬다. 두 방향 모두에서 factual records가 bitwise 동일한지 검사한다.

서로 독립적인 학습 64 blocks와 평가 48 blocks를 각 object–surface 조합에서 생성한다. Calibration pool seed는 1,034,000,000에서 시작하고 학습·평가는 400,000 간격, 네 family는 1,000,000 간격, 한 block당 환경 여덟 개를 분리한다. 평가할 조합과 object와 surface가 모두 다른 반대 조합 한 곳에서만 classifier를 fit한다. 같은 환경의 orientation 쌍과 두 schedules는 같은 split에 남긴다. Stage마다 별도 logistic ridge를 학습하고 penalty는 표준화한 feature에서 0.01, intercept는 무규제다. 읽을 수 있는 측정값으로 만든 signed impulse ratio와 RBF basis, factual 속도 및 두 방향의 interaction을 입력으로 쓴다. 일차 결과는 새로운 stage 2,4,8의 orientation Brier와 balanced accuracy다. 잘 보정된 무정보 확률 0.5의 orientation Brier는 0.25다. 같은 cluster를 재표집한 세 stage의 alternating−same orientation Brier에 simultaneous 95% interval을 붙인다. Conditional on fitted readout과 네 고정 조합이다.

별도 CPU 계산이 필요한 source Coulomb posterior의 정확한 15-feature와 frozen 1×1 ridge scalar에는 각 split의 첫 8 blocks per family로 동일 크기 readout을 fit하고 test한다. 이 작은 panel의 raw estimator도 동일한 8개 학습 blocks로 다시 fit한다. 2회와 4회에서 ① factual-only, ② raw action-aware summary, ③ 15개 scorer features, ④ 실제 frozen scalar의 orientation 정보량을 비교한다. Linear와 nonlinear readout 모두 관측 가능한 시작 방향과 측정 이력을 사용할 수 있다. Scalar의 nonlinear readout은 source-train 표준화 변수에서 고정된 RBF basis를 사용한다. 각 방법에 같은 convex logistic head와 같은 penalty를 적용한다. Feature 간 폭이 다르므로 이 비교는 해당 decoder class의 방향 복원 가능성에 대한 측정이다. 2↔4 stage의 표본과 항목들은 반복 측정이며 block 단위로 재표집한다.

특정 action으로만 관찰해도 방향 정보가 충분할 수 있다. Alternating의 orientation Brier가 raw의 held-out 평가에서 더 낮아지는지, 같은 raw panel에서 15-feature와 scalar 출력의 복원력이 낮아지는지 시험한다. Paired label permutation의 각 쌍 중 어느 sign이 plus인지 독립 동전을 던져 할당한 별도 control에도 같은 readout을 훈련·평가한다. Analytical factual chance와 permutation 결과를 함께 공개한다. 방향 분류 loss와 최종 stick outcome Brier는 label이 다르다. 정책별 gain과 실제 final Brier를 함께 보고해야 비용을 지불할 정보인지 평가할 수 있다.
