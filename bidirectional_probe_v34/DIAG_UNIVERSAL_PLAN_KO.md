# Family label이 필요 없는 orientation readout
첫 독립 물체·표면별 결과와 scalar 결과를 확인한 뒤, 한 모델을 모든 evaluation family에 쓰는 보조 검증을 추가한다. 양방향 반응이 있는 neutral reference 거리 프로필로 raw classifier를 새로 fit한다. Reference object의 curvature multiplier는 1이고 cubic slope는 0이다. Surface multiplier 1, asymmetry 0.20, speed scale 0.41을 사용한다. 이 네 값과 64개 train blocks는 OOD 결과에 맞게 선택하거나 최적화하지 않는다. v33 두 object·surface 계수 사이에 놓은 하나의 synthetic source이며 실제 물체에서 추정한 값은 없다. 1,045,000,000에서 시작하는 calibration seeds와 별도로 정한 1,046,000,000 기반 OOD test cohort(각 조합당 16 blocks)를 사용한다. Receiver는 이전과 같은 raw feature, logistic penalty와 action sequence를 쓰며 전체 test에서 같은 coefficients와 intercept를 적용한다. Domain shift 여덟 조건의 paired 3-way simultaneous intervals와 sign 별 active probing의 Brier를 보고한다. 이 late-designed sensitivity는 primary policy inference와 별도로 평가한다.
