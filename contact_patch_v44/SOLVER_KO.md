# 독립 contact solver와 사전 고정한 판정

서버에 설치된 PyBullet DIRECT(compile Jan 29 2025, API 202010061)를 사용한다. 표면은 contour의 위치만 샘플링한 triangle mesh, 동체는 질량 1의 이동 가능한 sphere 또는 capsule이다. 실제 충돌 법선·impulse·속도는 Bullet의 convex–concave detection, contact manifold, sequential impulse solver가 구한다. v43의 closed-form stick inequality는 호출하지 않는다. Material 입력에는 v43와 같은 surface field·speed law의 static coefficient를 최초 기하학적 지지점에서 평가 후 한 충돌 동안 고정해 쓴다. 독립 solver 효과에 friction semantics, mesh, event definition 변경도 함께 들어 있으므로 양쪽 solver 차이 전체를 수치적분법 하나에 귀속할 수 없다.

- Radius 0.5/2 mm, 수평 capsule의 straight sole span 0/2 mm, 실제 접촉 명령 중심 offset −0.5/0/+0.5 mm. 명목 19/31 mm. Span 0은 sphere다. Commanded sole span과 realized contact footprint를 구분한다. 후자는 한 step에서 양의 normal force가 작용한 manifold point 간 접선축의 최대 거리이고, 전체 impact 동안의 최댓값을 쓴다. 같은 접촉의 최대 동시점 수도 기록한다. 변형되지 않는 rigid shoe이며 재료의 Hertz contact area까지 측정한 실험은 아니다.
- Radius, span에 맞는 원호형 지지 곡선과 실제 mesh로 처음 닿는 높이를 구하고 0.03 mm 위에 동체 중심을 배치한다. 초기 world velocity는 수평 +0.425 m/s, 수직 −1 m/s. 회전을 고정하고 중력을 끈다. Shape와 각속도가 만드는 rolling을 구분하기 위한 translation-only impact다. 충돌 때 restitution e를 쓰고 표면 계수는 1로 둔다. 마찰은 한 target impact 동안 일정하며 static·kinetic transition의 v43 식을 그대로 쓰지 않는다.
- 표면 mesh 간격 0.10 mm, dt 20 μs, 80 solver iterations, 0.40 ms horizon, geometry/translation velocity 동일 50배 similarity scaling을 쓴다. Triangle 내부의 가짜 모서리를 제거하기 위해 Bullet internal-edge correction을 켠다. 이는 target을 열기 전 평면 무마찰 neutral fixture에서 선택했다. 이 옵션 전에는 수평 속도 0.425가 0.252 m/s로 잘못 줄었다. 보정 후 두 dt와 네 tool geometry 모두 마찰 0에서 0.425, 마찰 1에서 0, 마찰 0.02에서 약 0.389–0.391 m/s였다. [Neutral fixture](neutral_controls44.json)
- Label은 0.40 ms 후 측정한 중심 속도의 접선 성분 절댓값 ≤0.020 m/s이면 stick이다. 접선은 마지막 양의 하중을 받은 manifold에서 normal impulse로 가중해 구한다. 접촉 뒤 분리된 경우에도 이 접선에서 잰 잔류 미끄럼 속도로 판정한다. 끝까지 접촉한 사례는 별도 flag를 기록한다. 정상 접촉이 전혀 없으면 valid=false로 두고 손실에서 제외한다. 각 decoder에 같은 물체 mask를 사용하고 offset 간 비교 시 공통 mask를 쓴다. 0.01/0.04 m/s threshold는 같은 속도 원측정에서 재채점한다.
- 독립 catalog 12개에서 4 환경별 최초 8개 물체를 사전 선택하고 48 object/surface/law/variant/height cell을 교차해 221,184번의 primary impact를 생성한다. 모든 panel·cell에서 첫 환경의 첫 두 물체에 대해 dt를 반으로 또는 mesh 간격만 반으로 바꿔 각각 13,824번을 추가한다. 12개 catalog 외의 재사용된 noise·offset·mesh를 독립 표본으로 세지 않는다. [독립 구현](solver44.py)
