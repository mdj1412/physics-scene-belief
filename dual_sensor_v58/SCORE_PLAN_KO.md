# v58 평가 사전 명세

서로 다른 물체의 여덟 calibration impact를 두 센서가 동시에 읽는다. 8×1은 독립 session 여덟 개이고 4×2는 session 네 개에서 각각 순서가 무작위인 두 물체를 시험한다. 물체당 sign 판독 가능성은 0.5다. Source의 두 환경 후보 A, B는 v57과 같다. 잔여 변형 방향이 reference와 달라질 probability e의 평균은 두 후보 모두 0.29다. A와 B에서 E[e²]는 0.145와 0.0925다. A에서는 fixed 3R+I, B에서는 v54 gate를 사용하도록 등록하며 실제 새 catalog에서 이 mapping이 재현되는지도 기록한다.

두 sensor의 독립 net binary read error는 0.0392다. 같은 session에서 각 sensor가 확률 h로 고정된 Bernoulli(0.29) readout을 공유하며 이는 실제 physical sign에서 독립이다. 물체별 e가 독립인 rho=0, 같은 session에서 유지되는 rho=1, latch h=0, 0.26582278481012656을 교차하며 네 조건과 A/B를 균등 가중한다. Dual selector는 관측된 부호와 session membership만 받는다. 각 regime에서 session 내 pair likelihood를 적분한 뒤 네 session의 likelihood를 곱하고, 동일 pilot 전체에 적용되는 rho와 h의 네 후보를 균등 prior로 marginalize한다. 8×1에서는 같은 물체의 두 센서 간 agreement가 sensor artifact에 관해 알려줘도 A/B likelihood는 같다. 누락이 두 센서에서 같은 물체에 함께 발생한다. 무정보 MAP tie는 gate다. 

Primary는 dual 4×2 MAP vs dual 8×1 MAP의 balanced accuracy, mean held-out Brier, session loss p90다. 별도로 dual 4×2의 v57 single-channel naive MAP와의 차이를 같은 세 endpoint에서 보고한다. 각 endpoint의 두 비교는 별도 Bonferroni family다. 단일센서를 볼 때 sensor 0을 미리 지정한다. Naive MAP는 v57의 완전 판독 pair에 대한 LLR를 적용해 h와 read error를 교정하지 않는다. 추가로 nuisance-aware single-sensor MAP와 비교해 센서 개수의 incremental effect를 분리한다. Loss-weighted dual은 v56 source cost 기준 odds 2.016을 그대로 쓴다. Fixed 3R+I, v54 gate, true regime privileged를 포함한다. Oracle data, 실제 rho,h,A/B, 새 결과나 이름을 유입하지 않는다. Equal-weight economic result가 가정한 regime prevalence를 명시한다.

24개 catalog × 두 fresh surface와 두 rate law의 frozen physics decoder forecast, 기존 contact solver의 stick outcome에서 정책별 Brier를 paired로 계산한다. Mean은 전이확률에 대한 conditional expectation이다. Session p90은 독립 deployment seed의 128개 물체 binary realized Brier 평균이 이루는 분포의 weighted empirical inverse CDF다. 5,000회 paired catalog bootstrap을 쓴다. Realized mean 두 seed와 두 번째 p90, ultra solver, rho×h cell별 결과를 따로 기록한다. Cell 분석은 exploratory pointwise이며 별도 표기를 준다. Calibration 2,048회는 같은 surface에서 finite-pilot uncertainty를 적분하기 위한 replicate다. 독립 surface 개수로 해석하지 않는다.
