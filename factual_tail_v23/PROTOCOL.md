# V23 prospective protocol
Predefine a matched two-family Coulomb impulse simulator in physics23.py. Independent worlds, no mining of realized action margins. Same world, factual evidence, query label and standard-normal observation noises under primary (precise) and degraded (all additional sensor noise times 24) conditions. Same physical candidate prior as world generator; inference never receives the family, latent variables, trial observations or labels. Known calibration is shared by all policies. This changes the prior, query configuration and sensors relative to v22. Families are evaluation strata only. Single one-step stick outcome, common full 16,384 inner-bank decoder, all three potential observations observed in simulation.
Develop gate cutoff as median of factual score (resolution 512) on 96 independent development worlds (seed 23110617; pilot bank 237001,238003). Above cutoff retain exactly 3K/4 strongest weights and stratify K/4 slots by candidate label with group mass conservation, else factual top K. Run ordinary top-K and always-preserve at gate K,M as ablations. Primary methods: gate, best development top-K, original fixed global K128 and 4096 outer samples. Development ranking by actual Brier on 96 precise development worlds, calibration timings on separate 48 worlds (23120621); K candidates initially 2048,2560,3072,3328,3584,4096,4608 at M2048 and 1024,1280,1536,1792 at M4096, plus 6144,7168 at M1024 (when sampler supports K). Stage 1 first 24 worlds 1 timed repeat. Stage 2 remaining 24 x3 on nearest four per family plus fixed. Among triples with all p90 ratios 0.94–1.06, minimize sum of development Brier (then worst log-ratio). If no triple, closest worst log-ratio. Report all candidates. No padding. Test tolerates 0.90–1.10 inclusive on primary comparisons; no retuning using test outcomes.
Four fresh independent pairs, 512 new independent worlds (seed 23130731), 32 fresh noise repeats per action, both sensor settings. Freeze all policies before reading test responses. Joint family-wise test of primary gate-minus-top and gate-minus-fixed Brier on precise worlds (97.5% crossed bank/world bootstrap intervals, 20,000 draws). Claim advantage only if both upper bounds <0 and all three pairwise p90 ratios within tolerance. Report neutral, family, gate firing, forced-branches, flips, compute and per-bank sensitivity. Shared bank/noise repeated measures not independent. Time synchronized batch-1 online fit, gate, acquisition, chosen sensor posterior update on one idle allocated GPU; ignore world generation, offline setup and physical sensing time equally.
Validate design independently: rank the three actual per-world mean Brier scores from half the noise repeats. Measure runner-up minus best and worst minus best on the opposite half; average both directions. The stress setup passes if mean runner-up-minus-best >=0.03, and its increase vs degraded control has a paired 95% lower bound >0. Report metrics regardless. In addition fix geometry→query view and friction→probe in advance and compare to the other-family mapping on all repeats. These references see family or evaluation results; neither is a deployable policy. Offline gate association uses family only for evaluation. Decisions over all 512 worlds, no subgroup-based superiority claim.
