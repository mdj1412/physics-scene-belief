# Target 생성 전 추가한 source control

Primary는 PLAN_KO.md에 동결한 transferred router다. 기존 projection axis에서 얻은 규칙을 공통 source axis에 옮기는 점이 대안 설명이므로, secondary control은 과거 v44 evidence에 **동일 공통 axis**로 재추론하고 과거 point law의 center outcome으로 여섯 x bin의 D를 추정한다. 각 bin에서 D<0인 경우만 projection한다. 여섯 bin을 estimated x·oracle x·nominal x에 똑같이 적용한다. 과거 source 계산과 새 target 평가를 별도 파일에 두고 primary와 별도로 보고한다. Source control의 미래 결과를 보고 어느 arm을 대표로 삼을지 선택하지 않는다.
