# Source에서 결정한 soft projection의 전이
v45 fold/ripple의 finite contact patch 두 면적을 균등 평균한 Brier에서 하나의 전역 alpha를 선택한다. Grid는 0,.25,.50,.75,1이며 동률이면 더 작은 alpha다. 위치 route가 projection을 선택할 때만, whitened residual의 source axis 성분을 1−alpha 배로 만들어 squared Gaussian likelihood에 사용한다. V45 location router는 v46에서도 그대로 사용한다. 12 catalog 전수, 환경당 128 draws, paid noise 반복 4개를 포함한다. 선택 결과를 저장한 후 v46의 12 catalog에서 고정된 alpha minus 0, alpha minus hard의 두 사전 비교에 대해 catalog paired t interval을 Bonferroni 보정한다. 다른 alpha와 family별 curve는 기술용이다. 과거에 출판 준비 단계에서 본 v46 archive에 대한 재분석이다. Probe arm은 원래 posterior를 유지한다. 양 끝 alpha는 동일 archive의 원본과 hard decoder 출력으로 재현 검산한다.
