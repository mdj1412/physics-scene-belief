# v13 — Test 이전 protocol

2026-11-12 KST. 가설: compact predictive residual로 model mismatch를 감지하고 probe 또는 model expansion을 선택하면 unseen contact law의 decision loss를 줄일 수 있다.

Base compact는 v12 GH5/4-step Gaussian-sum filter를 유지한다. Pre-score는 boundary profile만 update한 posterior에서 factual velocity의 approximate mixture predictive negative log density다. Factual velocity를 fit한 뒤 같은 velocity의 residual로 detection하지 않는다. Pre-threshold는 matched calibration512 worlds의 97.5% upper quantile로 고정한다. Primary policy는 pre-flag면 probe, 아니면 base LMMSE action이다. Post-score는 factual posterior에서 실제 선택된 observation의 predictive negative log density다. 별도의 matched calibration512 worlds에서 이 policy를 그대로 실행한 score의 97.5% upper quantile를 고정한다. Pre 또는 post flag이면 model expansion한다. 이는 finite calibration의 empirical false-alarm control이며 sequential coverage theorem을 주장하지 않는다.

Expanded candidate는 기존 4 models에 geometry별 flexible tangential impulse 2 models를 추가한다: j_t=v_t sigmoid(b0+b1 log((|v_t|+0.02)/0.5)), b0~U[-4,2], b1~U[-2,2]. Base total prior mass .5, flexible .5. All components는 구현 단순화를 위해5D Gaussian state를 유지하고 base models의 extra2 dimensions는 nuisance다. GH3/4-step을 test 전에 고정한다. Target law의 정확한 family를 menu에 삽입하지 않는다. Model expansion은 factual와 selected observation을 새 prior에서 replay하며 full posterior moments/weights를 사용하지 않는다.

New independent base worlds256 ×6 paired conditions: matched, viscous replication(lambda .25–.65), saturating half/full, speed-weakening half/full. Half는 base Coulomb와 shifted impulse를 50:50으로 섞는다. Saturating: jt=sign(vt)*alpha*scale*tanh(|vt|/scale), alpha .35–.85, scale .25–.65. Speed weakening: jt=vt*(.12+alpha/(1+(|vt|/scale)^2)), alpha .3–.6, scale .2–.6. Frictionless c0는 unchanged negative control, c1만 law가 바뀐다. Boundary는 matched families를 유지한다. Same parameters/factual noise/additional noise를 공유하고 actual observation noise16 repeats를 사용한다. Calibration에서는 held-out law data를 전혀 사용하지 않는다. Viscous는 v12에서 이미 관찰한 family이므로 replication으로 명시하고 saturating/weakening을 새 held-out functional forms로 다룬다. Flexible candidate가 일부 law를 근사/표현할 수 있으므로 모든 test laws가 candidate support 밖이라고 주장하지 않는다.
