# v27 prospective protocol

Primary estimand: equal-weight risk over the eight design-specified target environments (off-grid alpha pairs relative to v26); three independent calibration and evaluation populations per law, three numerical bank pairs blocked by replicate. Source (1,1) and (0,+/-1) controls are separate. No selection of policies or hyperparameters from held-out outcomes. The design is a fixed panel, not a random sample of deployment shift laws. Bank effects are not separately identifiable from replicate effects. IID calibration worlds are essential. Simulation-only, same observation calibration and contact law as v25; unseen strengths, not unseen physics models. Positive and negative friction laws have the same population factual density. Fit one profile parameter with uniform prior and integrate the unidentified axis to its neutral value; 0 on that axis is a modeling choice, not measured stability. No labels, query views, probe measurements, cell, environment ID, or physical parameters in estimator. Distinct seeds across independently generated contexts and evaluation populations; Q/P noise paired across methods per world. Use fixed v25 gate and source K256, known-prior K256 using privileged true environment but no world latent, source always-query and neutral K256. Measure all policy choices with native decoders plus selection under common known-prior decoder. Estimate value specific to using batch data vs neutral K256 separately. All costs are squared deviations from binary stick outcome, not classification errors. Positive signs for losses correspond to worse performance.

Primary effects: estimated minus each of the five comparators, for native and common-known decoder, across 8 laws. Crossed-by-replicate, paired world/bootstrap: each draw resamples three shared replicate blocks with replacement; within each chosen law/rep resamples held-out worlds independently, paired across methods and action contrasts. Use 10,000 draws and a simultaneous max absolute standardized bootstrap band across 10 contrasts, and per-law descriptive contrasts. Bank population uncertainty is imprecise with only 3 bank pairs. Sensitivity hold out each replicate. Define evidence of Brier improvement if the upper simultaneous bound is below zero, distinguish a benefit to measured batch information from fixed neutral/marginalization. Do not treat failure to detect as equivalence. Exploratory source trade-off, action switches, sign and magnitude of calibration uncertainty, prior external to banks. Compute warmed batch-1 synchronized end-to-end selection + chosen-observation decoding on the same card; paired world timings interleaved within each env, N=16 * 2 timings per method and block. Also report static library, batch fit, engine setup, conditional and calibration-amortized latency; real physical sensor and collection of calibration worlds outside GPU timing. Additional environments include evaluations at opposing friction axes for identifiability. Assess feasibility, falsification, scientific novelty relative to test-time population conditioning and task-aware experimental design. No training on test laws.
