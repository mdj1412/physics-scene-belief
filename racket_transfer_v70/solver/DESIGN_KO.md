# v70 source-only holdout solver protocol

6개 보유 rubber마다 해당 제품의 모든 blade·sponge 구성을 함께 제외한다. Author train의 다른 제품으로만 parameter fitting하고 해당 제품의 author test를 primary로 사용한다. 공통 표본은 1,623개다. 같은 fit으로 held-out 제품의 author train도 순전한 추가 test로 평가해 총 8,113개에 대한 sensitivity를 보관한다. 전처리는 저자 scoring과 동일한 planar vx, vz와 ωy, R=0.020m, I/(mR²)=2/3, s=vx−Rωy를 사용한다. Racket angle, trajectory directory, rubber ID는 predictive input에서 제외한다. Author 코드가 이미 racket frame의 vx,vz를 모델에 직접 제공하므로 두 번 회전시키지 않는다.

1. v69 inclined rigid. 입사 및 이탈 center-of-mass velocity를 fit set에서만 기울어진 frame으로 회전한다. 후보 각도 0~35° 1° 간격, friction 0~1 간격 .025, 추가 1.1/1.25/1.5/2.0. 회전된 정상 성분의 최소제곱으로 e를 구해 [0,1]에 제한한다. 수평속도 및 rim velocity의 평균제곱오차를 합쳐 후보를 고른다. Target에서도 v69의 양의 기울기 convention을 유지한다. 부호 양쪽이 들어가는 racket impact에서는 ±35° sensitivity도 평가한다. 접근하지 않는 effective normal의 test shot에는 identity를 반환하고 건수를 기록한다. 무회전은 flat rigid control이다.
2. v69 two-regime affine. Positive/negative source release surface speed s_out을 label로 삼아 source-standardized inlet 3성분에 logistic gate를 fit한다. Ridge=1이며 intercept는 제외한다. 같은 source 두 집단에서 각각 affine least squares를 fit한 뒤 test 시 incoming만으로 한 expert를 선택한다. 별도 single affine, source mean, 반사+spin 보존 control을 둔다. 효과가 실제로 gate에 기인하는지 single affine와 대조한다. 또 저자의 constant elastic tangential impulse α 및 restitution을 source에서 fit한다. 이 α는 rigid rolling cap의 제약을 벗어날 수 있다.
3. Test shot 속도 오차는 (vx,vz)의 Euclidean norm (m/s), spin은 |wy 오차| (rad/s)다. 각 표본을 같은 가중치로 학습·평가한 micro, 제품당 가중치를 동일화한 macro를 구분한다. 표본마다 ground-truth, 예측값, split/row와 error를 보관한다. 위 목표에서의 상대적 개선을 평가하며 robot task의 성공 오차 임곗값은 정하지 않는다.
