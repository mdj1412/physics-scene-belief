첫 세 markered GelSight Mini sequence ID 1·2·3을 사전 선택한다. 각 sequence의 첫 episode에서 처음 240 frame까지 영상과 직접 대응시킨다. Frame index와 실제 저장 timestamp, ATI wrench, 압력 배열을 확인한다. 같은 RGB 영상에서 B/G/R channel만 따로 읽은 marker tracker의 출력 안정성을 기술한다. 이는 조명 방향을 실제로 바꾼 실험과 구분한다. 신뢰 가능한 공통 marker 위치는 grayscale의 Shi–Tomasi corner에서 세 채널의 forward–backward optical flow가 각각 0.5 px 이내인 경우로 정하고, frame마다 최대 100개 서로 다른 feature를 동일하게 추적한다. 간격은 5 frame이며 중복 없는 window를 쓴다. 수평 이동 절댓값이 비교한 두 channel 모두 0.2 px 이상일 때 부호 불일치율을 낸다. Corner마다 정답 identity를 제공하지 않으므로 이 측정의 분모는 유효 feature-window이고 오인식, strain, action, Brier를 추정하지 않는다. 각 episode를 개별 제시하고 같은 물체 내 frame을 독립 실험으로 세지 않는다.
