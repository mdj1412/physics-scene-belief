# v59 · 두 쌍둥이 환경, sensor reset과 camera의 사전 명세

두 환경 A/B는 균등하며 marginal physical mismatch q=.29와 v58의 second moment m_A=.145, m_B=.0925를 사용한다. 각 환경에서 physical persistence(P) 또는 common-mode electronic error(C)를 균등 교차한다. P에서는 같은 session의 서로 다른 물체의 true mismatch pair T가 q와 m_z를 가지며 electronic upstream U=T다. C에서는 true mismatch가 물체마다 독립이고, 확률 c_z=(m_z−q²)/(q(1−q))로 두 센서에 같은 session-wide Bernoulli(q) phantom이 들어간다. 이때도 U pair는 P와 동일 법칙이다. 이론적 동등성을 검산하기 위해 C의 U를 P의 T와 일치시키는 paired coupling을 사용한다. 이는 각 arm의 관측·정답 joint law를 바꾸지 않는다. Pilot cause는 이후 deployment decoder·policy 손익을 바꾸지 않으며, deployment regime A/B와 독립이다.

각 electronic sensor에만 session별 독립 Bernoulli(.26582278481012656) local latch를 추가한다. Latched sensor는 확률 q로 mismatch인 자기 phantom을 두 물체에서 반복하고, 다른 경우 upstream U를 본다. 물체 순서는 각 쌍에서 independent AB/BA. 두 번째 물체 직전에 fair coin으로 고른 한 sensor만 reset하며 이 local latch가 완전히 해제된다고 가정한다. 짝지은 no-reset에는 같은 shadow ID를 사용한다. Upstream artifact, 반대편 sensor 및 물리 표면은 그대로 유지한다. Reset 전후의 selected sensor와 bystander를 따로 보고한다. 물리적 session 시작은 4회, impact 8회, reference 8회, contact에 대한 reset 16회이며 전자 sensor reset만 0/4회로 달라진다. 한 물체의 변형이 판독 가능한 확률 .5이다. 각 전자 sensor의 R/I sign은 독립 오류율 .02다. 독립 camera는 같은 접촉에서 true R, I를 읽고, active일 때 .80 확률로 유효하며 R/I sign 각각 .03 오류율을 가진다. Camera를 꺼 둘 때는 같은 영상판독을 가린다. Camera가 upstream artifact를 공유하는 sensitivity를 추가한다.

예정 지표는 ① 두 sensor 사이와 camera에서 측정한 double mismatch 및 marginal을 뺀 covariance, ② randomized reset의 selected sensor·bystander 효과, ③ 각 팔에서 cause와 regime을 구별하는 single-pilot balanced accuracy다. Cause accuracy는 regime을 marginalize하고 tie는 C로 해소한다. 24개 fresh catalog, material 2개씩, 각 cell에 material당 2,048개 여덟-impact pilot을 사용한다. 95% CI는 5,000회 paired catalog bootstrap으로 구하고 원인 통계는 pointwise interval로 보고한다. 실물 sensor는 사용하지 않는다.
