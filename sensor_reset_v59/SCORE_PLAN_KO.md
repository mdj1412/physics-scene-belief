# 같은 여덟 impact에서 sensor reset과 camera를 비교하는 v59 사전 명세

표면별 네 session의 둘째 물체에 진입할 때 무작위로 고른 local sensor 한 개의 latch를 완전히 해제한다. No-reset arm에는 같은 무작위 channel ID를 pseudo-target으로 부여한다. 아날로그 common-mode 상태와 물리적 마찰은 두 arm에서 같다. 독립 camera는 같은 impact를 동시에 읽으며 active object의 80%에서 사용할 수 있다. 각 reference/impact sign의 오류율은 두 local sensor가 각각 2%, camera가 3%다. 결측은 원인에서 독립이다. Sensor latch probability는 26.5823%다. Pilot 관측은 네 session 내 mismatch bit 두 개, camera mismatch bit와 결측 여부, 무작위 reset ID가 전부이며, method는 각 pilot의 관측만으로 작동한다.

Population은 서로 독립적으로 교차한 원인 P/C와 배포환경 A/B에 각각 1/2 prior를 적용한다. A와 B의 평균 true mismatch는 0.29다. P에서 두 물체의 실제 mismatch second moment는 A=.145/B=.0925이고, C에서 물체는 독립이다. C에서는 두 local sensor에 앞선 common mode가 각 환경의 해당 second moment와 동일하도록 설계했다. Camera가 원인을 구별해도 A/B를 반드시 더 잘 구별하는 것은 아니다. A에서 fixed 3R+I, B에서 v54 gate가 낫다는 대응과 loss-sensitive cutoff(odds 2.016)는 v56 결과에서 고정한다. 새 표면에서 실제 손익 방향을 확인하고, 매 arm에서 동일한 v53 nominal continuous joint terminal을 사용한다.

정책은 알려진 네 candidate likelihood를 열거해 네 session의 log likelihood를 합하고, 원인을 marginalize한 A:B MAP로 행동을 정한다. 동률이면 gate를 쓴다. 원인 판별은 A/B를 marginalize해 별도로 계산한다. Camera off에서는 그 관측을 완전히 marginalize한다. 추가로 네 arm의 source-risk 행동과 always gate·fixed·privileged regime 대조를 표시한다. 전체 cohort는 24개 독립 catalog, 각각 두 재질과 두 rate law다. 표면당 2,048 pilot replicate는 inference의 독립 단위가 아니다.

Primary contrast는 camera를 함께 살 때의 reset 효과 r1c1−r0c1이다. 미리 정한 다른 세 contrast는 camera 없이 reset하는 효과 r1c0−r0c0, reset한 조건에서 camera의 효과 r1c1−r1c0, reset하지 않은 조건에서 camera의 효과 r0c1−r0c0다. 각 endpoint의 네 contrast를 Bonferroni 동시 95% CI로 판정하며 primary에는 별도 pointwise 95% CI를 더한다. 평균 held-out Brier는 새 deployment 물체의 binary label 분포를 적분한 값이다. Session loss p90은 독립 deployment seed의 128 물체 binary draw에서 구한 session별 평균 손실 분포의 inverse CDF다. 5,000 paired catalog bootstrap으로 같은 물체와 future label을 대조하고 두 realized seed 및 ultra solver에서 mean 차이를 재확인한다. 원인별 결과, interaction, source-risk threshold 결과는 secondary 또는 exploratory다. Simulator와 error family는 알려져 있으며, fresh catalog에서 threshold나 모델을 추정하지 않는다.
