# 개별 충돌에서의 Brier 부호와 전체 평균이 바뀌는 이유

같은 물체와 실제 binary stick label y에 대해 optimizer의 예측을 c, 고정 보정의 예측을 f라고 쓰면 Δ=(c−y)²−(f−y)²=(c−f)(c+f−2y)다. 두 예측은 같은 base probability에 각각 βzw와 βz·0.325를 log-odds로 더한다. 따라서 0 < base probability < 1이라면 c−f의 부호는 z(w−0.325)의 부호와 같다. y=0이면 두 번째 인수는 양수이고 y=1이면 음수다. 따라서 각 시행에서 **sign(Δ)=sign[z(w−0.325)](1−2y)**다. 두 보정이 같거나 base probability가 끝점이면 두 방법이 동률이다.

V40에서는 같은 family·law에서 contour를 바꿔도 y,z,w가 모두 같다. 따라서 개별 물체·noise에서 contour가 승자를 반대로 만들 수는 없다. 이미 optimizer가 이기는 시행에서 줄어드는 손실과 지는 시행에서 늘어나는 손실의 **크기**가 바뀌어 전체 Δ를 움직일 수 있다. 이 성질은 두 sigmoid 보정의 순서와 binary Brier에 의존한다. 두 모델이 서로 다른 관측으로 z나 w도 바꾸는 정책에는 같은 결론을 적용할 수 없다.

각 시행의 두 확률에서 실제 제곱오차를 다시 계산했다. 총 56,623,104개 평가 중 |Δ| > 10⁻¹²에서 위 부호 항등식 위반은 0건이었다. 37,748,736개 base–변형 쌍에서 양쪽 모두 이 기준을 넘으며 승자가 뒤집힌 경우는 0건이었다. 부동소수점 값을 0과 직접 비교했을 때의 부호 반전은 105,474건이며 모두 10⁻¹² 이내 값이 포함된 쌍이었다. 한쪽에서만 |Δ| ≤ 10⁻¹²인 쌍은 151,909개, 양쪽 모두인 쌍은 17,478,723개였다. 같은 관측과 label을 공유하는 반복이므로 이 건수는 독립 물체 수를 나타내지 않는다.
