# v60 · 새 outcome을 열기 전 정책 채점 계획

주평가는 **deployment 환경과 장치 common-mode fault 빈도가 독립**일 때로 지정한다. 교환 배정은 C에서 발생률 두 수준을 각각 표면별 A와 B에 1/2씩 배정하는 정확한 표준화다. 물리적 지속 P에서는 원래 surface A/B의 물리법칙을 유지한다. 원인 P/C 및 실제 배포 환경 A/B에는 균등 prior를 적용하고, +2 ms 뒤늦게 시작하는 impact의 비중 0%, 20%, 100% 세 조건을 1/3씩 평균한다. Posterior와 이 평가 가중치는 별개다. Frozen v59 selector는 matched-source likelihood와 sign error를 그대로 쓰고 target fault 빈도·지연·실제 원인·regime 및 deployment label에는 접근하지 않는다. 관측은 카메라 표식을 이용한 frame readout, reset 배정, 전자센서 R/I 부호에서 얻은 유료 mismatch와 결측이다.

Primary policy는 v56에서 고정한 손익 비율 2.016을 cutoff로 쓰는 loss-weighted rule이다. Marker-corrected reset+camera를 (1) marker-corrected sham+camera의 같은 rule, (2) 항상 v54 gate와 비교한다. 평균 held-out Brier 두 contrast의 동시 95% CI 상한이 각각 0 미만이어야 두 대조보다 유리하다고 판정한다. 24개 fresh catalog를 단위로 한 paired bootstrap 10,000회, 두 비교에 Bonferroni 보정. 다른 endpoint의 family도 각각 두 대조에서 동시 보정한다. 예측 행위가 A에서 fixed 3R+I, B에서 gate를 골랐는지 평가한 '정책 판별률'과 physical/common cause MAP의 '원인 판별률'을 분리한다. 분류 목적의 MAP action과 source-loss action을 둘 다 평가한다. 상시 gate는 P/C 진단을 내리지 않으므로 원인 판별률 칸은 비운다. 선택 가능한 두 행동의 평균 Brier ordering이 실제 각 surface에서 재현됐는지도 보고한다.

Secondary는 matched·independent·reversed fault assignment × 3 delay, 각 조건별 실제 policy accuracy·cause accuracy·mean·session p90 및 corrected reset−sham/gate다. 9개 cell 내 두 mean contrast는 하나의 18개 family로 동시 보정한다. Other contrasts, ablation, fixed high/low fault rate와 cause별 분석은 exploratory이다. Camera에 marker를 보이는 여부(보정/미보정)와 실제 reset/그대로 두는 sham을 교차한다. 비교 단위는 항상 같은 8개 impact, 16 contacts와 16 mechanical resets이다. Electronic reset·camera setup·compute 비용은 별도 장부로 계산한다. 독립 환경의 primary population은 실제 운영에서 세 지연 비중이 같다는 추정치가 아니다.

평균은 두 rate law·새 물체·공통 frozen decoder의 conditional expected binary Brier다. Session p90은 독립 binary replay seed로 얻은 128개 물체당 average Brier 분포에서 직접 계산한다. Subgroup별 p90을 평균하지 않는다. Target truth는 채점에만 사용한다. 사전 지정된 independent population에서 두 번째 binary replay의 p90·두 replay의 realized mean·ultra solver 민감도를 계산한다. 같은 catalog 안의 material/물체/512개 Monte Carlo pilot은 독립 catalog 수로 간주하지 않는다.
