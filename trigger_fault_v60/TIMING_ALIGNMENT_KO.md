# v60 timing과 loss 모집단의 정렬

사전 timing 계획의 9개 cell을 여전히 모두 측정한다. 별도로, 주 loss 분석이 surface fault 빈도와 deployment의 연결을 끊은 independent population에 정의되므로, 동일한 72개 crossover block 중 independent에 해당하는 24개(모든 catalog에서 1개, 지연 비율별 8개)를 추출해 별도 p90과 paired catalog bootstrap 동시 95% CI를 두 primary 대조에 제공한다. Hazard 세 관계를 균등 가중한 전체 72개 p90 및 각 cell 8개 p90도 함께 제공한다. 독립 모집단과 전체 모집단을 서로 대체하지 않는다. 이 정렬은 첫 GPU timing 전 결정했으며, 표본을 늘리거나 실행 순서를 바꾸지 않는다.
