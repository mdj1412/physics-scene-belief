# V25 prospective design
Primary physical manipulation, methods, splits, margins and seeds are fixed before test. See physics25.py for the exact bounds. One constant noise calibration for all stages/cells, identical query impact. Fully crossed curvature spread × friction spread (narrow/wide, independently jittered and signed); imperfect factual cues via the conditional offset and restitution distributions. No knowledge of cells, signs, labels or unselected observations in deployment. Keep all worlds. New train 3072 worlds seed 2511001; validation 1024 seed 2512001; test 1280 seed 2513001, 320 per cell. 32 actual post-action sensor noise replicates, same physical truth across actions/methods. Two matched disjoint Sobol bank pairs for training label averaging, one independent validation bank, five independent test pairs, 16,384 candidates per bank. All policies share full inner-bank posterior decoder for the selected observation. Primary actions query view or physical probe. Extra unrestricted K256 control may select factual view.
Primary gate is a new model, not a renaming of v24. Off-line train a host predictor of mean Brier(probe)−Brier(query) via simulated intervention responses on training worlds only, using factual profile mean/slope/curvature/residual RMS and outgoing factual velocity. Quadratic ridge or polynomial+96 fixed Gaussian RBFs, penalties .0001/.001/.01, width 1.8. Large absolute predicted advantage directly chooses action with lower predicted Brier; low confidence falls back to K1024 label-stratified always-preserve posterior acquisition. Confidence cut uses 20th,40th,60th,80th percentiles of absolute training predictions; all validation candidates are compared by paired actual Brier, choose lowest validation mean then highest direct fraction then quadratic. Never tune after test. Direct shortcut bypasses acquisition and external bank fit, still updates same inner decoder. Compare original v24 frozen tail gate and support-only new gate (K128 when confident, K1024 otherwise). Other controls K256/M2048, always query, always probe, direct prediction, K1024, K128, fixed global (v18 kernel), unrestricted K256. Split-averaged training outcome advantage vs heldout physical labels in independent source worlds. Offline training is distinct from online latency.
Physical design passes if (i) >=10% of unique test worlds stably prefer each action (both disjoint 16-repeat halves agree on winner with bank-averaged advantage >=.02 each), AND (ii) lower one-sided 95% bound on cell2 probe−query >+.03 and upper bound on cell1 probe−query <−.03. Report cross-fitted realized action advantage, consistency across halves, cell effects; eventual-outcome-informed world winners are privileged and are not the choice of an oracle conditioned only on factual evidence. Numerical K1024/K256 acquisition action frequencies show whether public posterior also supports switching. Inspect physically informative choices without screening out failures.
Primary superiority requires BOTH paired one-sided 95% upper bounds <0 for gate−K256 and gate−always-query Brier (intersection–union); no accuracy decision implied by timing. Descriptive p50/p90 and paired ratio intervals, common unpadded host→GPU→chosen sensor update path at batch 1, 20 held-out worlds per cell × 4 block repeats × 5 banks. Count all online routing. Fixed actions bypass acquisition and external bank. Report failure of either comparator, shallow K128/K1024 interpretation, conditional effects, blind routing with same branch frequency, evidence limits. 10,000+ paired crossed bootstrap draws, worlds stratified by the four physical cells, shared bank resampling; at least 5000 timing draws with paired bank/world/repeat blocks. Freeze source + validation plan, then all tested actions before opening private test outcomes for analysis. Use one empty allocated GPU, separately charged offline simulation/training; no physical hardware experiments.
